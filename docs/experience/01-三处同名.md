# 01 · 三处同名

## 症状

插件装在 profile 里、`dsh plugin` 也报告成功，但界面里什么都不出现；没有异常、没有日志。

## 根因

宿主按**包名**解析 bundle，把工厂投递给浏览器，浏览器再按**同一个 key** 等待。
下面三处不一致，就是「永远等不到」：

1. `package.json` 的 `name`；
2. `cordis.patch.yml` 的行 `id` / `name`；
3. `lib/client.js` 的 `__ModuleLoader__.load({ id })`。

另一个变体：三处都改了，但**运行中的宿主不会收敛** —— 旧 bundle 的组合行不会因
`bundles` 移除而卸载，页面刷新会报「导入失败」，patch 里写 `disabled: true` 也压不住。

## 证据

- 表现是「插件列表里查无此行」或页面报 `1 条未激活 … 导入失败`；
- 改包名后即便磁盘状态正确，仍需**重启一次 app** 旧行才消失。

## 结论

- 三处必须逐字相同；包名只能 ASCII（npm 拒绝 CJK 包名）；
- 界面中文名只放 `locale/*.json` 的 `meta.title` 与 host 半 `name`；
- 改包名 = 需要重启 app 的变更，写进发版说明。
