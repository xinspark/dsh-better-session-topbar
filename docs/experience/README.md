# 项目经验

> 症状 → 根因 → 证据 → 结论。改代码前先扫一遍，避免把踩过的坑再踩一次。

| # | 条目 | 一句话 |
| --- | --- | --- |
| 01 | [三处同名](01-三处同名.md) | 包名不一致时插件静默不出现，且全链路无报错 |
| 02 | [折叠后解不开](02-折叠后解不开.md) | 用 header 宽度做滞回，折叠态再也恢复不了 |
| 03 | [下拉被盖住](03-下拉被盖住.md) | 不 portal 会被页面内容盖住；外部关闭不能用 pointerdown |
| 04 | [chip 文案识别](04-chip-文案识别.md) | 拿不到原生按钮把手，只能按 aria-label 认人 |
| 05 | [原生菜单接入](05-原生菜单接入.md) | 菜单交给宿主；第三方 DOM 注入器认不出自绘列表 |
| 06 | [locale meta 启动读取](06-locale-meta-启动读取.md) | 改 `locale/*.json` 必须重启 app，刷新页面无效 |
| 07 | [对账静默跳过](07-对账静默跳过.md) | 包改名后被记成「未安装跳过」，契约核对变成假绿 |
| 08 | [CRLF 按行正则失配](08-CRLF-按行正则失配.md) | 文件被写成 CRLF（仓库存 LF）：按行尾的正则失配、整文件变 diff |
| 09 | [官方图标与自绘图标重复](09-官方图标与自绘图标重复.md) | 官方后来自己加了 chip 图标，我们那枚补丁变成第二枚 |
| 10 | [asar 不等于 tarball](10-asar-不等于-tarball.md) | 同版本号下 asar 与 npm tarball 逐字节不同：对账要双侧取 tarball，否则把重建噪声当漂移 |
