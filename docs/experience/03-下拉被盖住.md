# 03 · 下拉被盖住

## 症状

下拉列表被聊天正文盖住，或者首行被侧栏网格遮住；列表里的「更多」点开后，列表先消失、
菜单也跟着没了。

## 根因

1. **层叠上下文**：下拉渲染在顶栏槽位内部，处于 header 的层叠/裁剪上下文里，页面内容
   （含第三方插件注入的按钮）会画在它上面 —— 原生 `Menu` 的 `portal: true` 就是同一个理由。
2. **事件时序**：外部关闭监听了 `pointerdown` / `mousedown`。它们先于 `click` 派发，
   列表被先行卸载，行内按钮或悬浮菜单的 `click` 永远收不到。

## 证据

- 原地渲染时列表首行被侧栏列网格盖住、聊天正文压在下拉上；
- 改成监听 `mousedown` 后实测：点「更多」→ 列表卸载 → 菜单关闭 / 重命名对话框不出现。

## 结论

- 下拉必须 `createPortal(listEl, document.body)`；
- 外部关闭只监听 `click`：`click` 派发时目标还活着，行/菜单项的 onClick 先执行，
  未阻止冒泡的列表外点击才关闭；
- 与原生右键菜单共存时，下拉全部关闭要显式 `contextMenus.close()`（我们的列表根节点是
  `role="menu"`，宿主会把它当成「菜单内部」，不显式收会留浮层）。
